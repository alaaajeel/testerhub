# المرحلة 5: مركز إشعارات الإدارة

الفرع: `feature/admin-notifications`، مبني فوق `feature/simpler-add-app`.

## لوحة الإدارة (`admin.html`)

- تبويب جديد «مركز الإشعارات»، يظهر للمالك ولأي مشرف يملك الصلاحية الجديدة «إرسال إعلانات الإدارة».
- نموذج قصير: النوع (إعلان / تحديث للمنصة / تعليمات مهمة)، الجمهور (كل المستخدمين / المطورون / المختبرون / مستخدم محدد بالبريد)، العنوان، النص.
- تأكيد قبل الإرسال. كل إرسال أو سحب يتسجل بنفس العملية في سجل الإدارة.
- السجل يعرض كل الإعلانات وحالتها، وزر «سحب» يخفي الإعلان بدون حذف. نص الإعلان ما يتعدّل بعد الإرسال.
- الإرسال لمستخدم محدد يحتاج صلاحية «عرض المستخدمين» حتى نلگى الحساب بالبريد.

## داخل التطبيق

- الجرس يعدّ الإعلانات غير المقروءة، ويعرض أحدث 3 بقسم «إعلانات الإدارة» مع رابط «كل الإعلانات» لصفحة السجل.
- حالة القراءة محفوظة بالخادم (`noticeReads/{uid}` بوقت الخادم)، فتطابق على كل الأجهزة. فتح الجرس يعلّمها مقروءة.
- كل طرف يشوف إعلانات «الكل» وإعلانات دوره الحالي. الرسالة لمستخدم محدد تظهر له وحده.
- التحميل عند الدخول، وعند فتح الجرس، وبعدها كل 10 دقائق كحد أقصى. أقل من 35 قراءة بكل مرة، فيناسب Spark.
- **إشعارات والتطبيق مسكّر:** خارج هذه المرحلة. تحتاج خادم موثوق (Cloud Functions أو خادم خارجي)، والمشروع على Spark.

## Firestore

- `announcements`: `kind`، `audience`، `broadcast`، `targetUid`، `title` (2–80)، `body` (2–1000)، `active`، `createdBy`، `createdAt`.
  - **الكتابة:** المالك أو مشرف بصلاحية `sendAnnouncements` فقط، باسمه وبوقت الخادم.
  - **التعديل:** `active` فقط. الحذف ممنوع.
  - **القراءة:** الإعلان العام لأي عضو مؤكَّد، والخاص لصاحبه وللإدارة.
- `noticeReads/{uid}`: صاحبها فقط.
- صلاحية مشرف جديدة `sendAnnouncements`، وإجراءا سجل `send_announcement` و`withdraw_announcement`. الصلاحيات الحالية ما تغيّرت.
- فهرسان: `announcements (broadcast ↑, createdAt ↓)` و`(targetUid ↑, createdAt ↓)`.
