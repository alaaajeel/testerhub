# نسخة مرشحة للنشر: مسودات ودعوات وتقارير ومحادثات

فرع `integration/mvp-candidate` يجمع طلبات #3 إلى #8 في نسخة واحدة. هذا الفرع هو المصدر الوحيد للقواعد المقترحة للإنتاج، ويحتوي ملف `firestore.rules` الكامل. لا تنشر قواعد أي طلب منفرد بعده.

## المنفذ فعلياً

حفظ مسودة التطبيق وتعديلها قبل النشر، اختيار المختبرين، دعوة قابلة للقبول أو الرفض وتنتهي بعد 7 أيام، فصل قبول الدعوة عن بداية عداد 14 يوماً، مهام محفوظة مع التكليف، تقرير يومي بملاحظة ومهمة بتوقيت UTC يتحقق منه الخادم، منع التقرير المكرر، ورسائل تعيد المحاولة بمعرف ثابت عند فقد تأكيد الشبكة. تبقى المشاريع والتكليفات والتقارير القديمة بلا Migration أو حذف.

## التحقق

- `npm test`: ‏55/55.
- `npm run test:rules`: ‏22/22 على محاكي Firebase Auth وFirestore.
- `npm run test:e2e`: ‏16/16 في Chromium بقياس Android وسطح المكتب؛ هذه ليست تجربة هاتف فعلي.
- `npm run build` و`npm run preflight`: ناجحان.
- GitHub Actions لهذا الفرع يجب فحصه بعد فتح PR؛ الاختبارات المحلية لا تثبت عمل Firebase Production.

## شرط الدمج والنشر

لم نتحقق من القواعد المنشورة حالياً أو إعدادات Auth في المشروع الحقيقي. Firebase CLI لا يحمل صلاحية إدارية، وقراءة محرر القواعد في المتصفح حُظرت تلقائياً بحد استخدام مراجعة الموافقات. لا تحاول تجاوز هذا الحظر. راجع فرق قواعد الإنتاج الحالية مع هذا الملف، ثم انشر القواعد الكاملة من هذا الفرع بحساب إداري مخول. اختبر حساب مطور وحساب مختبر فعليين، والدعوة والتقرير والرسالة والعزل بين حسابين. عند نجاح ذلك وGitHub Actions، ادمج PR الخاص بهذا الفرع، تحقق من Pages وتسجيل الدخول، ثم أغلق PRs #3–#8 المكررة.

## غير مكتمل

بلاغات أخطاء منظمة وصورها وإعادة اختبارها، إشعارات Firestore الدائمة وFCM، لوحة Admin بخادم موثوق، سياسة حذف البيانات والاحتفاظ، مراجعة استهلاك Firebase، أجهزة Android فعلية، وإثبات اشتراك Google Play الرسمي. لا تصف هذا الفرع بأنه MVP مكتمل أو منشور قبل تلك التحققات.
