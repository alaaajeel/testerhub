# نسخة التكامل للمرحلتين الثانية والثالثة

يجمع هذا الفرع طلبات المراجعة #3 و#4 و#5 في ملف قواعد واحد وواجهة واحدة. لا تنشر قواعد أي فرع منفرد بعده.

## تسلسل النشر

1. راجع فرق `firestore.rules` مع قواعد الإنتاج الحالية. تأكد من عدم وجود تعديل إنتاج أحدث غير موجود في هذا الفرع.
2. انشر **الملف الكامل** `firestore.rules` من فرع التكامل إلى مشروع Firebase `testhubiq-c7711` عبر حساب إداري مخول. لم نتمكن من قراءة محتوى محرر الإنتاج آلياً بسبب حد مراجعة الموافقات، وFirebase CLI غير مصادق عليه؛ لذلك نشر القواعد والتحقق منها إجراء خارجي مطلوب.
3. اختبر بقواعد الإنتاج حساب مطور وحساب مختبر حقيقيين: إنشاء مسودة، تعديلها، نشرها، قبول الاختبار، إرسال تقرير مهمة اليوم، وقراءة التقرير. يجب أن تفشل عمليات مستخدم آخر والتاريخ المزور والتقرير المكرر.
4. بعد التأكد من القواعد ونجاح GitHub Actions، ادمج طلب التكامل فقط إلى `main` وانتظر Pages، ثم تحقق من تسجيل الدخول من الرابط المنشور. أغلق الطلبات المنفردة #3 و#4 و#5 بعد دمج التكامل كي لا تعيد نشر شيفرة قديمة.

## ما تم اختباره محلياً

- `npm test`: 55/55.
- `npm run test:rules`: 19/19 عبر محاكي Firebase Auth وFirestore.
- `npm run test:e2e`: 14/14 على محاكي متصفح Android وسطح مكتب؛ هذه ليست أجهزة فعلية ولا حسابات Firebase Production.
- `npm run build` و`npm run preflight`: ناجحان.

لم تُنجز بعد حالات الدعوات التفصيلية، البلاغات المنظمة، Push، الإدارة، وخصوصية الحذف. لا تُعلن جاهزية MVP أو نشر هذه النسخة قبل إكمال دورة الحسابين الحقيقية.
