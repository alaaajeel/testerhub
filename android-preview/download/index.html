نسخة Android التجريبية

هذه صفحة تنزيل منفصلة عن المنصة الأصلية. حالياً رفعنا إعدادات البناء إلى GitHub، لكن APK النهائي يحتاج التحقق من نجاح البناء والتوقيع قبل فتح تنزيل عام.

فحص حزمة الاختبار على GitHub

هذا الرابط يفتح بناء GitHub Actions، وقد يتطلب حساب GitHub لتنزيل artifact. لا تعرض الصفحة رابط APK مباشراً غير موجود.

شلون تثبت النسخة إذا صارت جاهزة؟

  1. نزّل APK من رابط إصدار موثوق نعلنه بالصفحة.
  2. افتح ملف APK من التنزيلات، واسمح بالتثبيت من المصدر الذي اخترته إن طلب Android ذلك.
  3. افتح TesterHub V2 وسجل بنفس حسابك السابق.
  4. راجع حسابك وتطبيقاتك واختباراتك. هذي نسخة تجريبية، ولا تمس الـPWA القديمة.

الموقع الأصلي testiqx.web.app يبقى يعمل كما هو. لا يوجد تحويل إجباري ولا حذف للبيانات.
