# TesterHub V2 — Android Preview

هذه حزمة تجريبية **مستقلة**، من دون دمج أو نشر للموقع الأصلي. Package ID: \`iq.testerhub.v2.preview\`.

## ما يعمل حالياً
- تطبيق Android محلي يحتوي نسخة \`preview/v2/index.html\` ضمن assets بواسطة \`WebViewAssetLoader\`.
- تسجيل الدخول بحساب Firebase Auth الحالي بالبريد وكلمة المرور عبر Firebase Identity Toolkit REST API.
- الحصول على ملف المستخدم \`users/{uid}\` وعلى المشاريع المملوكة والتكليفات المسموح له قراءتها في Firestore REST، **للقراءة فقط**. الاستعلامات محددة بـ30 سجلاً للمجموعة، وتعمل عند الدخول فقط لتقليل حصة Firestore Spark.
- إبقاء \`UID\` والدور \`role\` الحاليين بلا تغيير؛ تظهر واجهة V2 بوظيفتي مختبر ومطور، لكن صلاحيات الكتابة ما زالت حسب قواعد الإنتاج القديمة.
- مجموعات Packs والعملات في واجهة V2 **محاكاة محلية**. لا يحق لهذه النسخة إنشاء مجموعات إنتاجية، أو تغيير الرصيد الحقيقي، أو التلاعب بالاختبارات الفعلية.
- لا يخزن التطبيق كلمة المرور ولا Firebase refresh token؛ النسخة التجريبية تطلب تسجيل الدخول بعد إعادة تشغيل التطبيق.
- فتح روابط Play والمجموعة خارج WebView في المتصفح/Google Play، ولا توجد واجهات Native Usage Access في أول بناء.

## البناء
تقوم \`.github/workflows/android-v2-preview.yml\` ببناء Android Debug APK على فرع \`feature/android-v2-preview-20261112\`. تضمّن الواجهة داخل ملف APK من \`preview/v2/index.html\` خلال البناء. يعتمد Android Gradle Plugin 8.7.3 وGradle 8.9 وJDK 17 وAndroid SDK 35.

المخرجات المتوقعة: GitHub Actions artifact باسم \`TesterHub-V2-Preview-APK\` وفيه \`app-debug.apk\`. ملف Debug للاختبار الداخلي فقط، وليس إصدار توزيع عام ثابت التوقيع.

## قبل التوزيع للمستخدمين
1. تجربة تسجيل الدخول على جهاز Android، مراجعة المظهر وتثبيت الروابط وتحقق Auth REST.
2. تحديث المنتج بمنطق حقيقي ثنائي الدور في Firestore Rules بعد تدقيق وتوافق الحسابات الحالية (لا يكفي إزالة اختيار الدور من الشاشة).
3. ربط واجهة V2 ببيانات التطبيقات والمجموعات الفعلية وفق قواعد الأمان؛ لا تخلط عينة المحاكاة ببيانات إنتاجية.
4. الاعتماد على مفتاح توقيع إصدار ثابت محفوظ في GitHub Actions Secrets؛ لا توزع APK debug على الجمهور وتعده قابل للتحديث الآمن لاحقاً.
5. صفحة التنزيل العامة تستلزم رابط APK عام موثوقاً (GitHub Release asset أو Hosting مستقل) قبل وضع الزر للمستخدمين؛ \`Actions artifacts\` ليست رابط تنزيل مباشر للجمهور.
6. لا تحوّل \`testiqx.web.app\` إلى صفحة إجبار المستخدم على تثبيت APK حتى يكتمل الاختبار ويوافق المالك.
7. حماية بيانات الاستخدام والخصوصية والإفصاح قبل إضافة مراقبة \`UsageStatsManager\` لاحقاً.
