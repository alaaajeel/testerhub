# TesterHub — نموذج تحقق أندرويد (تجريبي)

يثبت فكرة وحدة: هل نگدر نعرف على هاتف حقيقي إذا تطبيق **منصّب**، و**كم دقيقة انستخدم اليوم**؟

- بدون أي مكتبات، وبدون إنترنت. ماكو بيانات تنرسل لأي مكان.
- كشف التثبيت: عبر `<queries>` لتطبيقات الشاشة الرئيسية (بدون `QUERY_ALL_PACKAGES`).
- دقائق الاستخدام: صلاحية «الوصول لبيانات الاستخدام» (`PACKAGE_USAGE_STATS`) يفعّلها المستخدم من الإعدادات.

## التنزيل
GitHub ← Actions ← «Android verify PoC (APK)» ← آخر تشغيل ← Artifacts ← `testerhub-verify-poc-apk` (ملف zip بداخله APK).

ما ينشر على Firebase ولا يمس الموقع الحي. ما ينضم لـ main.
